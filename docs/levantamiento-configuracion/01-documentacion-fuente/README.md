# Documentacion fuente

Colocar aqui copias de los documentos que deban analizarse para configurar IntegraQ.

Ejemplos:

- Mapas de procesos.
- Organigramas.
- Listas de personal o usuarios.
- Matrices de responsabilidades.
- Procedimientos.
- Catalogos de clientes y proveedores.
- Listas de areas, puestos y centros de trabajo.
- Matrices de permisos o autorizaciones.

No colocar credenciales, contrasenas ni secretos de acceso.
