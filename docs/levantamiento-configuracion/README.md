# Levantamiento de configuracion de IntegraQ

Esta carpeta concentra la informacion necesaria para definir la configuracion base de IntegraQ antes de detallar formularios, flujos o integraciones.

## Prioridad del levantamiento

1. Procesos y subprocesos.
2. Areas y responsables.
3. Tipos de usuario.
4. Roles y permisos.
5. Clientes, proveedores y otros catalogos.
6. Alcance funcional de cada proceso.

## Carpetas

- `01-documentacion-fuente`: documentos actuales que se analizaran o extraeran.
- `02-alcance-procesos`: listado maestro para confirmar que procesos entran en IntegraQ.
- `03-configuracion-base`: definicion de usuarios, roles, permisos, areas y catalogos.

## Regla de trabajo

No se disenan formularios ni dashboards hasta confirmar el alcance del proceso y sus responsables.
