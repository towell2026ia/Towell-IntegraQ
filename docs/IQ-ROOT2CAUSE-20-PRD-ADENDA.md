# IQ-ROOT2CAUSE-20 — Adenda funcional P0

## Eliminación de enlaces técnicos a GitHub

Root2Cause y las demás pantallas operativas de IntegraQ no mostrarán botones, enlaces ni elementos de navegación que lleven a GitHub, repositorios de desarrollo o `Gronk93/CAPA-V01`. Se eliminará «Referencia» cuando abra ese repositorio. No se reemplazará por un enlace decorativo o externo.

Las referencias metodológicas oficiales que deban consultar los usuarios pertenecerán a Información Documentada de IntegraQ y respetarán sus permisos. Esta regla no modifica GitHub, CI/CD, Netlify ni avisos legales que deban conservarse fuera de la navegación operativa.

La validación de interfaz debe impedir que una URL de GitHub o el repositorio CAPA-V01 se reintroduzca en las pantallas operativas. Esta adenda no autoriza cambios funcionales o visuales adicionales.

## U08 · Correcciones funcionales postpublicación

La navegación visual forma parte del mismo candidato que el guardado del borrador, el recorrido de ocho etapas, Llenar A3 con IA, Ayuda IA y la apertura desde Reclamos. Quedan vigentes los criterios funcionales de ese PRD y el control de acceso RCA-07.

El usuario interno verá las vistas que autoriza su perfil, en este orden: Acciones correctivas, Análisis A3, Seguimiento de acciones y Registros retirados. Se retira de Root2Cause el acceso a la metodología. Los documentos originales conservan su ubicación en Información Documentada.

En el listado, tres tarjetas filtran las acciones vigentes por estado. Abiertas comprende todas las etapas anteriores al cierre. Los contadores se calculan sobre las acciones visibles del origen seleccionado. El origen admite Todas, Internas, Externas / Clientes y Sistema de gestión (auditoría y SGC). Cambiar el origen conserva el filtro de estado. Los borradores, retirados y registros de proveedores quedan fuera del resumen.

Calidad comprobará el cruce de filtros, la apertura del expediente por folio y el acomodo de controles y filas en escritorio, tablet y móvil. Esta revisión utiliza el contrato SQL ya previsto en el candidato P0.
